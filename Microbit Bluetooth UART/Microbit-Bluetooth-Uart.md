# Microbit Bluetooth UART
To connect and control the Microbit to bluetooth quickly, we can use bleutooth UART service.
Using  bleutooth UART service we can send and receive text and data over bluetooth just like a UART serial port. 

## Install the Apps
We need following Bluetooth serial terminal app for this project:
1. [Android App](https://play.google.com/store/apps/details?id=de.kai_morich.serial_bluetooth_terminal&hl=en_US)
2. [Apple iOS App](https://apps.apple.com/us/app/bluetooth-terminal/id1058693037)

## Pairing mobile phone with microbit
You need to pair the microbit with mobile phone first time when you are using it. Follow these simple steps
1. Turn on bluetooth on mobile phone
2. Power ON microbit and Hold down the A, B and reset buttons simultaneously.
3. While holding the buttons A & B, Release the reset button. The LED screen will fill and then show the Bluetooth logo
4. Find the microbit device in mobile phone bluetooth scan and pair
5. Reset the microbit
